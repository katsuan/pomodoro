# ⏱️ ぽもくる（PomoQ）

集中と休憩をくり返すポモドーロタイマー。名前は「ぽもくる」（ポモドーロ＋くり返しの「くるくる」）。英字は PomoQ（おくるん＝OQRN・さくせん盤＝SAQSEN・キロっく＝kiloQ と同じ作り方で、「く」を Q にする）。名前とロゴは設定（右下の ⚙️）の中にだけ出し、タイマーの画面はすっきりさせておく。

公開URL: https://katsuan.github.io/pomodoro/

## アイコン・ロゴ・OGP

`python3 tools/icon.py` で作る（図形を描く部分は `tools/brandkit.py`。countdown・gender-reveal と同じファイル）。

- アイコン（`icon.svg`・`icon-32.png`・`apple-touch-icon.png`・`icon-512.png`・`icon-maskable-512.png`）：おくるんと同じ角の丸い四角に、ポモドーロの黄色（style.css の --color-primary #F9BE00）のグラデーション。輪はおくるんの Q と同じく、くるくる回る時計回りの矢印（集中と休憩のくり返し）。30分を1周として 25分の作業を矢印、5分の休憩をすき間にし、すき間（右下）からしっぽを出して Q に見せる。上にトマトのヘタを兼ねたストップウォッチの竜頭、輪の中にタイマーの針
- 横長のロゴ（`logo.svg`）：P・o・m・o はフォント（Jua）、Q はアイコンと同じ形
- 共有したときの画像（`ogp.png`、1200×630）
- ホーム画面に追加したとき用に `manifest.json`

おくるんのトップの「ほかのツール」（line-share の `data/hub-links.json`）には「ぽもくる 〜PomoQ〜」として、このアイコン付きで載せている。

## URL パラメーター

| キー | 内容 |
|---|---|
| `work` / `break` | 作業・休憩の分（初期値 25 / 5）。この2つだけは URL に残し、ブックマーク・共有に使える |
| `start` | 区切りの起点（`9`・`9:30`・`0930`。初期値 9:00） |
| `counter` / `vol` | 回数・音量バーを出すとき `1`（初めは出さない） |
| `state` / `outside` | 状態欄・円や日時を消すとき `0` |

`work`・`break` 以外は、開いたときに端末（localStorage）に保存して URL からは消す（流入口の目印などのほかのパラメーターも消す）。設定は右下の ⚙️ からも変えられる。
